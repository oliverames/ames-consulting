The safety model

YNAB MCP starts in read-only mode. Writes require explicit opt-in and confirmation, and the server keeps an undo journal for supported changes. That is a better fit for financial data than treating every API action as equally harmless.

The tool set

The server exposes 58 tools and six guided prompts for budgets, accounts, transactions, categories, payees, months, scheduled transactions, and reporting. It converts YNAB milliunits into ordinary currency values at the boundary so calculations stay predictable.

Where it runs

It supports a local standard-input connection and a hosted OAuth connector. Both routes use the same underlying YNAB API and the same emphasis on explicit, reversible changes.
